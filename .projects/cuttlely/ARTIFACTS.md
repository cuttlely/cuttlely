# Artifacts

Where things live. Merged work is in `git log` and the closed pull requests (`gh pr list -R cuttlely/cuttlely --state merged`); open work is in the [issues](https://github.com/cuttlely/cuttlely/issues). This file does not copy either list.

## Docs

| What                                 | Where                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Product README and first ten minutes | `README.md`; translated READMEs in `i18n/`                                                                                                                                                                                                                                                                                                                                                                                                           |
| Docs index                           | `docs/README.md`                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| User guides                          | `docs/how-to/` (harnesses, context and tokens, analyst, ETL, canvas, versioning, share and embed, try the demo, the customer care demo, server settings, sign-in, Docker, from source, Render)                                                                                                                                                                                                                                                       |
| API guide and example app            | `docs/api.md`, `examples/web-app/`                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Reference                            | `docs/reference/` (override config, versioning settings and APIs, version files, model list, agent runtime upgrades)                                                                                                                                                                                                                                                                                                                                 |
| Identity                             | `docs/identity/` (AuthKit setup and identity behaviour)                                                                                                                                                                                                                                                                                                                                                                                              |
| Import from other tools              | `docs/bring-your-flows.md` and the import guides it links                                                                                                                                                                                                                                                                                                                                                                                            |
| Releases and upgrades                | `docs/releases.md`, `docs/upgrading.md`, `CHANGELOG.md`                                                                                                                                                                                                                                                                                                                                                                                              |
| Security and outbound connections    | `SECURITY.md` (including "What Cuttlely connects to")                                                                                                                                                                                                                                                                                                                                                                                                |
| Help and contact                     | `SUPPORT.md`, `CODE_OF_CONDUCT.md`; the general contact, info@cuttlely.com, is also in the README and the site footer                                                                                                                                                                                                                                                                                                                                |
| Credits and licenses                 | `CREDITS.md`, `NOTICE`, `LICENSE.md`                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Contributor guide and agent rules    | `CONTRIBUTING.md`, `AGENTS.md`, `.cursor/rules/`, `.cursor/skills/`                                                                                                                                                                                                                                                                                                                                                                                  |
| Architecture map                     | `ARCHITECTURE.md` and `architecture/boundaries.json`. `pnpm verify` runs `scripts/architecture-map.test.mjs`                                                                                                                                                                                                                                                                                                                                         |
| Health baseline                      | `docs/reference/health-baseline.md`. `scripts/health-report.mjs` prints the current figures. CI appends them and does not fail the job.                                                                                                                                                                                                                                                                                                              |
| Screenshots                          | `docs/images/` (taken from a running server with made-up data)                                                                                                                                                                                                                                                                                                                                                                                       |
| Website                              | `website/` (source); the pages come from `docs/` at build time. Content screenshots use `website/src/scripts/screenshot-viewer.mjs`. The home page demo video (`website/public/media/customer-care-demo.*`) is a narrated walkthrough of a real Try the demo run. The six product videos on the home page cards (`website/public/media/products/<slug>.mp4`, `-loop.webm`, `-loop.mp4`, `-poster.webp`) are real recordings with made-up bakery data |
| Brand assets                         | `assets/brand/`                                                                                                                                                                                                                                                                                                                                                                                                                                      |
