## Verification evidence

-   **Standalone tracing:** [full gate](https://github.com/cuttlely/cuttlely/actions/runs/44048907366), all 28 steps on `5224da37`, whose tree matches the merged change. The hosted standalone Harness completed an isolated database-tool query. External LangSmith dashboard ingestion was not independently inspected.
-   **ETL:** [full gate](https://github.com/cuttlely/cuttlely/actions/runs/44147463146), all 28 steps on the merged tree. ETL checks pass 358 cases with 12 existing pending cases. A controlled slow-bookkeeping fixture went from a five-second HTTP timeout to HTTP 200 in 77 ms, processing the same 600 generated sources. Interrupted Markdown content matches a clean run. These fixtures establish the reproduced mechanisms, not the unknown document errors from an older installation.
-   **First owner:** [full gate](https://github.com/cuttlely/cuttlely/actions/runs/44164822457), all 28 steps on `10c1fa89`, whose tree matches the merge. Focused tests pass 81 cases with two environment-dependent skips. Real CLI/SQLite startup and PostgreSQL migration, authentication, atomic audit and two-connection race probes pass. Live MySQL owner creation and the documented Docker CLI invocation were not independently exercised.
-   **Release candidate:** the earlier [preparation](https://github.com/cuttlely/cuttlely/actions/runs/44111606709) predates ETL and first-owner changes. Its version PR [#519](https://github.com/cuttlely/cuttlely/pull/519) is closed. Fresh full verification, image startup and protected version preparation are required for this source; the earlier candidate is not a publication receipt.
