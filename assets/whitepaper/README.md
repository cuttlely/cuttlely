# Benchmark whitepaper

**Lean context, reliable agents.** Same agent. A third of the tokens. Not one failed run.

-   [PDF](cuttlely-benchmark-whitepaper.pdf)
-   [Web version](cuttlely-benchmark-whitepaper.html) (self-contained HTML; download and open in a browser)

The website serves both files from this folder at [cuttlely.com/whitepaper](https://cuttlely.com/whitepaper/), so this folder is the only copy.

The paper compares token use and run reliability for one production agent rebuilt on several platforms, and explains its method and caveats.
