# A2A 0.3.0 JSON schema

`a2a-v0.3.0.json` is the A2A protocol JSON schema at tag `v0.3.0`.

-   Source: https://github.com/a2aproject/A2A/blob/v0.3.0/specification/json/a2a.json
-   Tag: `v0.3.0`
-   Licence: Apache-2.0

Tests load this file and validate HTTP bodies against named definitions (`#/definitions/AgentCard` and the JSON-RPC success and error shapes). Runtime request handling does not import it.
