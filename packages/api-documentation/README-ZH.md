# Cuttlely API 文档

[English](./README.md) | 中文

Cuttlely 的 HTTP API 文档，包括 `POST /api/v1/prediction/:id`。harness 预测返回 `text`、`harness`、`agents`、`sources`、`artifacts`。

在仓库根目录执行 `bash scripts/start-cuttlely.sh`，再在本目录执行 `pnpm start`。开发模式下于根目录执行 `pnpm dev`。文档地址：`http://localhost:6655/api-docs`。
