# 参与 Cuttlely

[English](../CONTRIBUTING.md) | 中文

开发环境、测试和环境变量以英文 [CONTRIBUTING.md](../CONTRIBUTING.md) 为准。

Cuttlely 是一个服务器：具名的 Hermes harness，以及按名字选用 harness 的对话流。本地同时启动 Cuttlely 与 Hermes：

```bash
pnpm install
pnpm build
bash scripts/start-cuttlely.sh
```

问题与改动请提到 [Cuttlely 仓库](https://github.com/cuttlely/cuttlely)。安全漏洞请按 [SECURITY.md](../SECURITY.md) 私下报告给 Cuttlely 维护者。不可接受的行为请在 Cuttlely 仓库开 issue 报告。
